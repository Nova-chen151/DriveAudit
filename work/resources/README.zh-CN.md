# 选手输入包

[![英文版](https://img.shields.io/badge/英文版-777777?style=flat-square)](README.md) [![简体中文](https://img.shields.io/badge/简体中文-2878B5?style=flat-square)](README.zh-CN.md)

将下载的 nuScenes 选手压缩包复制或软链接到 `work/resources/participant.tar.gz`。保留压缩格式，程序会自行解包所选场景。要直接使用其他位置的压缩包，请在[生成配置](../../configs/generation.json)中将 `archive` 设为对应路径。

任务要求、提交目录结构和校验命令见[赛题说明](../../docs/challenge.zh-CN.md)。运行基线模型的步骤见[生成指南](../../docs/generation.zh-CN.md)。
